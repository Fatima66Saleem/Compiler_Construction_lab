# Lab 5: DFA Concepts

This lab focuses on a Deterministic Finite Automaton (DFA), which is a more structured form of finite automata where each state has exactly one transition for each input symbol.

## Files

### `dfa.py`

The script demonstrates:

- defining states such as `q0` and `q1`
- processing input character by character
- checking transitions for each symbol
- accepting or rejecting strings based on the final state

This is a practical example of how a DFA can validate whether a string belongs to a particular language.

### Run it with:

```powershell
python Lab5/dfa.py
```

## Concepts Practiced

- DFA design and state modeling
- Deterministic transitions
- Final-state acceptance rules
- Simple language recognition in compiler theory

## Notes

The example uses a minimal finite automaton to show how a machine can decide whether an input string is accepted or rejected.
